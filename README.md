# Para python

El prototipo presentado por el equipo debe incluir como mínimo uno de los siguientes puntos:

Manejo de archivos y análisis con pandas: el prototipo debe leer al menos un archivo de datos (CSV, Excel, JSON, etc.) y realizar operaciones básicas de limpieza o transformación, como selección de columnas, filtrado, manejo de valores nulos o agregaciones simples (ej. groupby, value_counts). Uso de módulos, y correcta definición de paths.

Visualización de datos accesible: se deben generar gráficos que exploren o comuniquen información. Además, para que sea accesible, la visualización debe estar adaptada para tres tipos de discapacidades visuales (ej. usar paletas amigables para daltónicos, proveer textos alternativos, etc.). Pueden usar librerías como Matplotlib, Seaborn o Plotly.

Aplicación interactiva con Streamlit: como mínimo, deben incluirse la visualización adaptada a tres tipos de discapacidades visuales.  Permitir la interacción del usuario con los datos o gráficos mediante al menos tres widgets.

Problematica
    Antecedentes: A la hora de hacer el proyecto, nos parecio necesario poder darle un enfoque inclusivo a la descripcion de los espacios de nuestra casa de estudios ya que esto tiene un impacto real en nuestra comunidad.     Desafios encontrados: Realmente podemos hacer una aplicacion para todos ? La respuesta rapida es no. El desafio principal se encuentra en un diseño universal que contemple la amplia diversidad en la comunidad. En esta primera etapa, contemplamos solo un sector reducido: Daltonismo y Visibilidad reducida
